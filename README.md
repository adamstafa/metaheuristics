# Solver for the pickup and delivery problem with time windows
The repository contains implementations of metaheuristic algorithms for solving the PDPTW problem, written as part of a university course on metaheuristics.

## Features
- Algorithms
  - Local Search
  - Simulated Annealing
  - Adaptive Large Neighborhood Search
- Operators
  - Removal of n vehicles
  - Insertion of n vehicles at the greedily found best place
  - Insertion via minimum weight matching
  - Random reinsertion
